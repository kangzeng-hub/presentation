# Synthetic competitor analysis

This file is a public, synthetic fixture for local demonstrations. It contains no customer data, live scrape, private product information, or copied competitor imagery.

Synthetic observations:

- Product identity is usually established with a clean product-dominant composition and an explicit set count.
- Assortment and size choices are easier to scan when repeated labels and comparable panels are used.
- Material and mechanism claims should be presented as source-linked evidence, not as unsupported medical or performance promises.
- Wearing scenes can support style projection, but they must not replace canonical product identity evidence.
